# Contributing to staged

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## How to contribute

1. Fork the repository on GitHub and make your change on a branch.
2. Run `npm test`.
3. Open a pull request that says what you changed and why.

Forking to send a pull request is allowed by the [licence](LICENSE). Publishing your fork as its own app is not.
